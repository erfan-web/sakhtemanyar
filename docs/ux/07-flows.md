# ۷) یوزر فلاوها (User Flows) — گام‌به‌گام

نمودارهای متنی برای تبدیل به FigJam (هر فلش = یک اتصال).

---

## ۷.۱ ثبت ساختمان (آنبوردینگ مدیر) — MVP

```
شروع: ورود با موبایل (کد پیامکی)
  → [عملیات] اگر کاربر جدید → صفحه «ایجاد ساختمان»
    → ۱. نام ساختمان ← فرم ساده (۱ فیلد)
    → ۲. تعداد واحد ← شمارندهٔ گام (۱۰ تا ۵۰)
    → ۳. آدرس/محله ← فیلد متنی (اختیاری، با پیشنهاد)
    → ۴. شارژ پیش‌فرض ← عدد (تومان) + دوره (ماهانه)
    → ۵. افزودن واحد ۲: نام ساکن/مالک + شماره موبایل ← تکراری
      → [الگو] دعوت پیامکی خودکار به ساکنین
    → ✅ «ساختمان فعال شد» ← ویزارد تمام
  → اگر کاربر قبلاً ساختمان دارد → داشبورد
```

---

## ۷.۲ صدور شارژ ماهانه (مدیر) — MVP

```
داشبورد → «صدور شارژ ماه»
  → تأیید مبلغ پیش‌فرض (یا ویرایش)
  → [سیستم] ایجاد کارت واحد برای هر واحد با وضعیت «در انتظار پرداخت»
  → ارسال پیامک اطلاع‌رسانی به ساکنین
  → کارت وضعیت واحدها (رنگی)
    ├── پرداخت: سبز | بدهکار: قرمز | در انتظار: زرد
  → [تک‌تک] ثبت هزینه (دسته، مبلغ، رسید)
```

---

## ۷.۳ پرداخت شارژ + تأیید (ساکن + مدیر) — MVP

```
ساکن = خانه → «شارژ من» → مشاهده مبلغ و مهلت
  → انتخاب «پرداخت خارج از اپ» (کارت‌به‌کارت)
  → ثبت رسید: شمارهٔ پیگیری + عکس (اختیاری)
  → وضعیت ← «در انتظار تأیید مدیر»

مدیر = کارت وضعیت ← ورودی «در انتظار تأیید»
  → تأیید یک‌دکمه‌ای → وضعیت سبز + پیامک رسید
  → [خطا] رسید ناقص → درخواست اصلاح (پیام)
```

---

## ۷.۴ ثبت و پیگیری درخواست تعمیر (ساکن + مدیر) — MVP

```
ساکن = خانه → «ثبت درخواست تعمیر»
  → ۱. نوع (شکسته/مشکل) ← دسته‌بندی (آسانسور/لوله/برق/سایر)
  → ۲. شرح + عکس (پیش‌نمایش)
  → ۳. ثبت ← وضعیت «باز»
  → اعلان پیامکی به مدیر

مدیر = لیست درخواست ← مورد جدید «باز»
  → تعیین زمان/فرد ← وضعیت «در حال انجام» (+ اعلان به ساکن)
  → پس از انجام: ثبت مبلغ/نتیجه ← «انجام شد» (+ اعلان + سابقه)
  → [خطا] عدم پاسخ در ۲۴س → هشدار مدیر (SLA ساده)
```

---

## ۷.۵ اطلاع‌رسانی (مدیر) — MVP

```
مدیر = «اطلاعیه جدید»
  → عنوان + متن + [اختیاری] فوریت
  → ارسال ← اعلان درون‌برنامه + پیامک برای حالت فوری
  → ثبت در تاریخچه + نشان «ارسال شد»
```

---

## ۷.۶ حالت‌های خطای مشترک (Error States)

1. **شماره/کد نامعتبر** → پیام روشن + دکمهٔ «ارسال دوبارهٔ کد» (۶۰ ثانیه تایمر).
2. **فرم ناقص** → اعتبارسنجی درون‌خطی با پیام فارسی و رنگ قرمز.
3. **پرداخت ناموفق** → متن دلگرم + امکان بازگشت و تلاش مجدد (بدون از دست رفتن داده).
4. **خطای شبکه** → صفحهٔ «اتصال ندارید» + دکمهٔ تلاش مجدد.
