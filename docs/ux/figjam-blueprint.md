# فیگ‌جام «ساختمان‌یار کرج» — بلوپرینت کپی/پیست

فایل: https://www.figma.com/board/hdb95ItZ6AZVrHwrYgwGMl/Untitled (هسته: hdb95ItZ6AZVrHwrYgwGMl)

چون اسکیل‌های FigJam محدود به خواندن/نظر است، این سند «بلوپرینت» است: هر بخش = یک Section، هر مورد = یک Sticky Note با رنگ‌بندی. دنبال ترتیب زیر بچینید؛ سربرگ بخش‌ها را از منوی FigJam (Section) بسازید.

---

## طرز استفاده سریع
1. FigJam را باز کنید (لینک بالا).
2. برای هر بخش، یک **Section** با همان عنوان بسازید.
3. استیکینوت‌ها را به‌ترتیب داخل هر بخش اضافه کنید (کلید U یا از Toolbar).
4. رنگ هر استیک را طبق کد زیر تنظیم کنید.
5. برای User Flows با ابزار Connector/Arrow بین استیک‌ها اتصال بکشید.
6. استیکینوت‌هایی که علامت 🎯 دارند، اصلی/مشهور هستند (اندازهٔ بزرگ + فونت درشت).

**رنگ‌ها:** 🟨 زرد = عنوان/هدر | 🟩 سبز = قابلیت/جریان اصلی | 🟦 آبی = اطلاعات/پیام | 🟧 نارنجی = درد/نقطهٔ ضعف | 🟪 بنفش = فرصت/ایده | 🟥 قرمز = خطا/خطر | ⬜ سفید = توضیح

# بخش ۸ — یوزر فلاو (User Flow: آنبوردینگ/صدور شارژ/پرداخت/تعمیر/اطلاعیه)

> این بخش با **Connector** رسم شود. استیک‌های زرد = شروع/پایان؛ سبز = گام؛ قرمز = خطا؛ بنفش = تصمیم.

### ۸.۱ آنبوردینگ مدیر
`ورود موبایل (کد) → [جدید؟→ ساخت ساختمان] → ۱نام → ۲تعداد واحد → ۳آدرس ← ۴شارژ پیش‌فرض → ۵واحدها (+دعوت پیامکی) → ✅ فعال شد`
**(۵ استیک سبز + ۱ زرد «ساختمان فعال شد»، شامل ۱ نارنجی تصمیم «جدید؟»)**
### ۸.۲ صدور شارژ ماه
`داشبورد → صدور شارژ ماه → تأیید مبلغ → ساخت کارت هر واحد → پیامک به ساکنین → کارت وضعیت رنگی(سبز/قرمز/زرد)`
### ۸.۳ پرداخت + تأیید
`شارژ من → پرداخت خارج از اپ → ثبت رسید → «در انتظار تأیید» → (مدیر) تأیید یک‌دکمه → ✅ سبز + پیامک | 🟥 رسید ناقص → درخواست اصلاح`
### ۸.۴ ثبت درخواست تعمیر
`ثبت درخواست → نوع → شرح+عکس → وضعیت «باز» → اعلان مدیر → (مدیر) تعیین زمان → «در حال انجام» → مبلغ/نتیجه → «انجام شد» + سابقه | 🟥 بدون پاسخ ۲۴س → هشدار`
### ۸.۵ اطلاع‌رسانی
`اطلاعیه جدید → عنوان+متن(+فوریت) → ارسال → تاریخچه + نشان «ارسال شد»`
