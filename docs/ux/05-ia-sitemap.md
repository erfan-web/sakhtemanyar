# ۵) معماری اطلاعات + نقشه سایت (IA / Sitemap)

روش: کارت‌سورت ترکیبی (ترکیبی از باز و بسته) — ورودی فرضی.

## اصول دسته‌بندی

- دو نقش کاربری: **مدیر** و **ساکن**.
- بیشترین درهم‌ریختگی رقبا در بخش مالی است → در MVV به‌جای ۱۰ منو، ۳ منوی اصلی برای مدیر.

## نقشه سایت — نمای مدیر

```
ورود (شماره موبایل + کد پیامکی)
└── خانه (داشبورد امروز)
    ├── شارژ (بخش اصلی مالی)
    │    ├── صدور شارژ ماهانه
    │    ├── کارت وضعیت واحدها (پرداخت/بدهکار)
    │    ├── ثبت هزینه (دسته + مبلغ + رسید)
    │    └── گزارش/صورت‌وضعیت (PDF)
    ├── درخواست‌ها (تعمیرات)
    │    ├── لیست درخواست‌ها (باز/در حال انجام/انجام شد)
    │    ├── جزئیات درخواست (عکس، مبلغ، نتیجه)
    │    └── تغییر وضعیت + ثبت هزینه تعمیر
    ├── اطلاع‌رسانی
    │    ├── اطلاعیه جدید (نوشتن + ارسال هم‌زمان پیامک)
    │    └── تاریخچهٔ اطلاعیه‌ها
    └── ساختمان
         ├── واحدها (+ ساکنین)
         └── تنظیمات (شارژ پیش‌فرض، روش پرداخت)
```

## نقشه سایت — نمای ساکن

```
ورود (همان) → خانه
  ├── شارژ من (مبلغ ماه، پرداخت شده؟)
  │    └── راهنمای پرداخت (MVP: کارت‌به‌کارت + تائید مدیر)
  ├── درخواست من
  │    ├── ثبت درخواست تعمیر (دسته + شرح + عکس)
  │    └── پیگیری وضعیت
  └── اطلاعیه‌ها
       └── جزئیات اطلاعیه
```

## اعتبارسنجی IA (برنامه)

- کارت‌سورت آنلاین با ۱۰–۱۵ شرکت‌کننده از هر نقش.
- تست درخت (Tree Test) برای «یافتن صدور شارژ» و «یافتن وضعیت تعمیر».
